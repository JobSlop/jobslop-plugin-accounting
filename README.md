# Accounting — a jobslop plugin

ICAEW and ACCA job boards, your accounting qualifications in the profile (filled in on applications), and accounting job titles in Dutch, Spanish and Danish.

## What it adds

- **Job boards:** ICAEW (Chartered accountancy jobs (ICAEW)), ACCA (Accounting & finance jobs (ACCA Careers))
- **Profile fields** (the Chrome extension fills them in on application forms): Accounting qualification (ACA, ACCA, CIMA, AAT…), Exam stage / level reached, ACCA membership number, ICAEW membership number, Accounting software you use (Xero, Sage, SAP…)
- **On screen:** see `ui.js` (tabs, map layers or Progress cards)
- **Its own words in:** da, es, nl

## Install

It comes with jobslop — switch it on in **Settings → Plugins**.

To get a newer version before jobslop's next release: **Settings → Plugins → Check for plugin updates**,
or paste `https://github.com/JobSlop/jobslop-plugin-accounting` into **Install from link**.

## Making changes

See the plugin guide, `docs/PLUGINS.md` in the [jobslop repository](https://github.com/JobSlop/jobslop).
Raise `version` in `plugin.json` and publish a GitHub release tagged `v<version>`.
